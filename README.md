# Norns Manual

A searchable reference for four monome norns instruments played from a grid and an OXI E16: Mutated, Circuit Breaker, Fractured and Still.

Open it at https://micrograinfilms.github.io/norns-manual/

Type a question (for example "mutated mutes"), pick an app to see its grid and E16, tap any answer to light its keys on the board, or tap a key or knob to see every move that uses it.

The page is one self contained file, `index.html`. Its content comes from each app's README and code in its own repo.
